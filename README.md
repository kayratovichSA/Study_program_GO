# Практикум Go: главы 2–5

Одно настольное приложение Fyne v2 с четырьмя настоящими вкладками. Это авторские упражнения по темам METANIT, а не официальный набор заданий сайта. Глава 1 включена только в конспект NOTES.md.

## Запуск в VS Code на Windows

1. Распакуйте ZIP целиком. Откройте папку `go-study` через File → Open Folder либо файл `go-study.code-workspace`.
2. Установите рекомендованное расширение Go от Google, если оно ещё не установлено.
3. В терминале VS Code, находясь в папке с `go.mod`, выполните:

```powershell
go mod download
go run .
```

Первый запуск загружает зависимости и компилирует графическую библиотеку, поэтому занимает больше времени. Интернет нужен для загрузки зависимостей. Уже установленный Fyne повторно вручную устанавливать не требуется: версии задаются в go.mod/go.sum.

Нужны Go 1.23 или новее, GCC в PATH и CGO. Проверка:

```powershell
go version
gcc --version
go env CGO_ENABLED
```

Последняя команда должна вывести `1`. При необходимости для текущего терминала:

```powershell
$env:CGO_ENABLED = "1"
$env:PATH = "C:\msys64\ucrt64\bin;" + $env:PATH
go run .
```

Путь GCC выше подходит только для установки MSYS2 UCRT64 именно в этой папке. При ошибке `gcc not found` проверьте фактический путь и перезапустите VS Code после изменения PATH. При ошибках OpenGL обновите драйвер видеокарты. Официальная инструкция: https://docs.fyne.io/started/.

## Задания

| Вкладка | Упражнения |
|---|---|
| Глава 2 | Калькулятор, знак и чётность числа, таблица умножения, массив `[5]int` |
| Глава 3 | Вариативная сумма и несколько результатов, рекурсивный факториал, функция как параметр, замыкание-счётчик |
| Глава 4 | Передача значения и указателя, обмен через указатели |
| Глава 5 | Структура с вложенной структурой и методами, срез/append/сортировка, частоты слов, справочник на map |

Каждое упражнение содержит пояснение, поля и вывод результата. Ошибки ввода отображаются внутри соответствующей карточки. Карточки прокручиваются. Справочник и счётчик сохраняются при переключении вкладок, но сбрасываются при закрытии приложения. Кнопка «Выполнить» использует текущие поля; в упражнениях с указателями поля остаются исходными данными для нового опыта.

## Исходники и проверка

- `main.go` — создание приложения и окна.
- `ui.go` — вкладки, карточки, ввод и обработчики кнопок.
- `logic.go` — учебные функции, указатели, структуры.
- `logic_test.go`, `ui_test.go` — проверки вычислений и интерфейса.
- `NOTES.md` — краткий авторский конспект глав 1–5.
- `VERIFICATION.md` — фактически выполненные проверки и ограничения.

```powershell
go test ./...
go build -o go-study.exe .
```

Можно также выбрать Terminal → Run Task → «Запустить практикум Go». Для изучения найдите соответствующую функцию в logic.go и обработчик в ui.go, измените алгоритм и повторите запуск. GUI использует библиотеку, выходящую за первые пять глав; учебная логика отделена от неё.

Источник тем: https://metanit.com/go/tutorial/2.11.php (оглавление глав 1–5).
