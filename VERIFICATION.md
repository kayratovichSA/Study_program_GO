# Результаты проверки

Проверено 13 октября 2026 года в Windows amd64: Go 1.27.1, GCC из MSYS2 UCRT64, CGO_ENABLED=1, Fyne v2.6.3.

- `go mod tidy` — успешно; go.sum включён в проект.
- `go test logic.go logic_test.go` — успешно.
- `go test -tags ci ./...` — успешно. Тестовый драйвер Fyne проверил четыре вкладки, их переключение, выполнение карточек с исходными данными и точный результат кнопки калькулятора. Также проверены арифметические операции, деление на ноль, недопустимые числа, сумма/min/max, факториал 0 и 20, преобразование, замыкание, обмен и изменение через указатель, метод структуры.
- `go vet -tags ci ./...` — успешно.
- `go test ./...` с обычной конфигурацией Windows — успешно после завершения сборки.
- Дополнительно проверены отображение ошибки деления на ноль, два вызова и сброс счётчика, сохранение/поиск/удаление в справочнике; карточки со стартовыми данными не выдали ошибок.

Флаг `ci` использует программный драйвер для автоматических тестов; он не подтверждает отображение настоящего окна Windows. Визуальная проверка окна и интерактивный запуск `go run .` не выполнялись.

Обычная сборка Windows успешно завершена командой `go build -buildvcs=false -o ../../work/go-study.exe .`. Флаг buildvcs отключает только запись сведений Git в бинарный файл: в окружении проверки родительский репозиторий был недоступен. Код графического приложения собран с настоящим Windows-драйвером и CGO; исполняемый файл не запускался. В распакованной отдельной папке используйте обычное `go run .`; при ошибке получения VCS status можно выполнить `go run -buildvcs=false .`.
