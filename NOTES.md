# Краткий конспект глав 1–5 METANIT

Это самостоятельное краткое изложение тем оглавления, а не восстановленный текст предыдущей беседы. Источник: https://metanit.com/go/tutorial/2.11.php.

## 1. Введение
Go — компилируемый язык со статической типизацией. Программа начинается с объявления пакета. Исполняемый проект использует `package main` и функцию `func main()`. Импорты подключают пакеты. `go run .` собирает и запускает пакет текущей папки; `go build` создаёт исполняемый файл. Модуль описан в go.mod. Практических заданий главы 1 в приложении нет.

## 2. Основы
`var` объявляет переменную; `:=` — краткое объявление внутри функции. Тип может задаваться явно или выводиться из значения. Основные типы: целые числа, float32/float64, bool, string. Переменная без явной инициализации получает нулевое значение. `const` задаёт константу. `fmt.Printf` форматирует вывод через `%d`, `%g`, `%s`, `%v`.

Арифметика: `+ - * / %`; остаток `%` применяется к целым. У целых деление отбрасывает дробную часть. Сравнения дают bool; `&&`, `||`, `!` объединяют условия. Побитовые операции работают с битами целых: `& | ^ &^ << >>`. Присваивание `+=` сокращает изменение значения; `++` — отдельная инструкция.

`if` выбирает ветвь по условию, `switch` сравнивает варианты. `for` — единственная конструкция цикла; `range` позволяет обойти коллекцию. `break` завершает цикл, `continue` переходит к следующей итерации. `[5]int` — массив фиксированной длины; длина входит в тип. Индексы начинаются с 0. Выход за границы вызывает панику.

Практика: Calculate; chapter2 (проверка числа, цикл таблицы, настоящий массив).

## 3. Функции
Функция принимает параметры и может возвращать несколько значений: `func MinMax(v []int) (int, int)`. Аргументы передаются по значению. Вариативный параметр `values ...int` получает произвольное число аргументов; срез раскрывается вызовом `Sum(v...)`.

Функции имеют тип, могут передаваться как параметры и возвращаться из функций. Анонимная функция не требует отдельного имени. Замыкание сохраняет доступ к переменным окружающей области даже после завершения внешнего вызова. Рекурсия — вызов функции самой себя; нужен базовый случай и ограничение входа.

Практика: Sum, MinMax, Transform, Counter, Factorial. Factorial проверяется на диапазон 0–20 в обработчике перед вызовом.

## 4. Указатели
`&x` получает адрес переменной; `*int` — тип указателя на int; `*p` читает или изменяет значение по адресу. Нулевое значение указателя — nil, разыменовывать его нельзя. Передаваемый указатель тоже копируется, но копия указывает на ту же переменную. Поэтому функция может изменить исходное значение через `*p`. Обычная передача int изменяет только копию.

Практика: IncrementValue, IncrementPointer, Swap. Адрес в выводе может отличаться между выполнениями.

## 5. Производные типы
`type Age = int` — псевдоним того же типа; `type Age int` создал бы отдельный определённый тип. Структура объединяет именованные поля разных типов. Поле структуры может само быть структурой. Метод объявляется с получателем: `func (s Student) Description() string`. Получатель по значению получает копию; `func (s *Student) Birthday()` меняет исходную структуру.

Срез `[]int` имеет длину len и ёмкость cap, ссылается на базовый массив. Срезы одного массива могут разделять данные. `append` возвращает обновлённый срез и при необходимости создаёт новый массив, поэтому результат нужно присваивать. Для независимой копии используют make/copy или append в новый срез. Сортировка меняет переданный срез.

`map[string]int` связывает ключ с значением. Перед записью карта должна быть создана через make или литерал. Чтение отсутствующего ключа возвращает нулевое значение; форма `value, ok := m[key]` отличает отсутствие ключа. `delete` удаляет ключ. Порядок обхода map не гарантируется, поэтому интерфейс сортирует ключи для стабильного вывода.

Практика: Student/Address, Birthday, карточка среза, карта частот, справочник.
